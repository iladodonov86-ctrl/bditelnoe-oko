# Бдительное Око — первая версия

Демонстрационный веб-проект на Java 17, Spring Boot, Thymeleaf, Spring Security и H2.

## Запуск
1. Установите JDK 17 и Maven.
2. Откройте терминал в папке `bditelnoe-oko`.
3. Запустите: `mvn spring-boot:run`
4. Откройте `http://localhost:8080`.

По умолчанию локальный демонстрационный администратор:
- логин: `President`
- пароль: `change-me-now`

Перед первым запуском можно задать собственные данные:
- Linux/macOS: `export OKO_ADMIN_USERNAME=President` и `export OKO_ADMIN_PASSWORD='длинный-уникальный-пароль'`
- Windows PowerShell: `$env:OKO_ADMIN_USERNAME='President'` и `$env:OKO_ADMIN_PASSWORD='длинный-уникальный-пароль'`

Если база уже создана, изменение переменной пароля не обновит пароль существующего пользователя. Для чистого демонстрационного старта остановите приложение и удалите папку `data/`.

## Важно
Это локальный демонстрационный интерфейс в художественной стилистике. Не вводите реальные адреса, сведения о реальных людях или иные чувствительные персональные данные. Не публикуйте приложение в интернете без отдельного аудита безопасности, управления секретами, резервного копирования и настройки доступа.

База H2 хранится в `./data/`. Консоль H2 выключена по умолчанию.
